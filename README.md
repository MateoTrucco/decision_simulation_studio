# Decision & Simulation Studio

A reproducible Monte Carlo workbench for comparing two uncertain decisions. It turns a small random-number experiment into a defensible analysis tool with seeded simulations, downside percentiles, break-even probability, sensitivity analysis and CSV exports.

## What it demonstrates

- A deterministic, dependency-free simulation engine
- Input validation and explicit statistical summaries
- Side-by-side decision analysis rather than a meaningless score
- Interactive distribution and sensitivity visualizations
- Hand-written English and Spanish UI, device-language detection and shared theme preferences
- Responsive and keyboard-accessible browser interface

## Run locally

Serve this directory with any static server, then open `index.html`. The engine has no runtime dependencies.

```bash
npm test
```
